# Security and responsible use

- All data in this repository is synthetic. Do not commit real transaction exports, phone numbers, bank details, or personal data.
- A risk score is an investigation lead, never proof. A human must review before any account is frozen or reported.
- If you suspect real fraud, report at https://cybercrime.gov.in or call 1930 (India).
- Found a vulnerability in this code? Open a private security advisory on GitHub instead of a public issue.
